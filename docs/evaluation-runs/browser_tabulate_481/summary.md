# Browser-to-artifact evidence

This case proves the product path that the API/receipt cases cannot: a real
browser submitted a public GitHub issue URL, watched the run reach a terminal
state, rendered the plan/artifact, and downloaded the generated files.

## Input

- **Browser:** Chrome (headless, Playwright), viewport 1440x1000
- **Web:** `http://localhost:3000`
- **API:** `http://localhost:8000` (in-process execution, WSL bubblewrap sandbox)
- **Issue:** https://github.com/astanin/python-tabulate/issues/481
- **Run:** `run_20261026-100340_8a5rrl53`
- **Pinned commit:** `268615a5c27dc40e5c22454c07b44d5c50410da0`

## Result

- **Status:** `COMPLETED`
- **Planner:** `heuristic-v1` (the demo API was intentionally started without a
  model key; see the caveat below)
- **Artifact:** `DOCS_DIFF` touching `README.md`
- **Documents:** `CONTRIBUTION_PLAN.md`
- **Checks:**
  - `patch-path-policy` — `PASSED`
  - `patch-applies-on-pinned-commit` — `PASSED`
  - `sandbox-egress-isolation` — `PASSED`
  - `repository-test-suite` — `PASSED`
- **Comparison:** `NO_REGRESSION_DETECTED` (baseline and post-patch suites both
  passed)

## Browser actions that were executed

1. Opened `http://localhost:3000`.
2. Filled the issue URL field with the public issue URL.
3. Clicked **Start run** and waited for the run page.
4. Waited for the persisted record to reach `COMPLETED`.
5. Reloaded the run page and verified the rendered record showed the artifact,
   plan and verification receipt.
6. Clicked **Download** on the documentation patch and on
   `CONTRIBUTION_PLAN.md`.
7. Saved both downloaded files under `downloads/`.

## Caveats

- The demo API had no model credentials, so the planner is the deterministic
  `heuristic-v1`; the UI and plan disclose that identity. This is a browser/UI
  proof, not a claim that the live model produced this patch.
- The live-model path is evidenced separately:
  [`live_model_observation_094908`](../live_model_observation_094908/summary.md)
  succeeded with `model:openai/deepseek-v4.1`; the final matrix's live case
  failed with a gateway 524 and is preserved honestly in
  [`docs_tabulate_481_live`](../docs_tabulate_481_live/summary.md).
- The generated documentation section is mechanical and explicitly marked
  "Generated by RepoMate; verify wording against project conventions." It is
  not presented as a reviewed upstream patch.
- One browser console 404 remained (the web app has no favicon route); it did
  not affect the run, API calls or downloads.
